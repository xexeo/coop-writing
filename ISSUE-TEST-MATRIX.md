## Closing rule

No issue in this table should be closed merely because code exists on a branch. Closure requires:

1. implementation in canonical `coop-writing.dtx` (or a deliberately external tool for #53/#67);
2. regression/static/compatibility evidence listed above;
3. PR #70 merged to `main`;
4. a closing comment naming the implementation and test evidence.
