## Summary

Editorial workflow support for collaborative LaTeX documents.

## Description

`coop-writing` provides a source-controlled editorial layer for collaborative LaTeX documents. It supports comments associated with collaborators, proposed insertions/removals/replacements, TODOs, draft material, anonymization for blind submission, paragraph subject/main-idea markers, editorial lists, and mode-dependent input/include behavior.

The package is designed so that editorial information remains in the LaTeX source instead of depending on a particular editing interface such as Overleaf. The same source can therefore be compiled for editing, blind submission, or clean publication using different package modes.

Version 1.5.5 consolidates the post-1.2.4 development line currently published on GitHub and fixes TODO default behavior and hyperref-option/conditional handling. The release documentation is UTF-8 and includes English and Brazilian Portuguese quick references and maximal examples.

## Announcement text

Version 1.5.5 is a substantial update to `coop-writing` since the CTAN 1.2.4 release. It adds and documents the later editorial workflow features developed in the 1.3-1.5 series, including blind-review helpers, mode-dependent file inclusion, configurable anonymization display, improved suggestion handling, color helpers, and inline TODO support. This release also fixes the default TODO behavior so that inline boxes are opt-in, corrects hyperref conditional/option handling, removes an unnecessary xstring dependency, and refreshes the UTF-8 documentation with English and Brazilian Portuguese quick references and maximal examples.
